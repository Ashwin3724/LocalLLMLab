START HERE

Install Ollama and models

Install and start Ollama on this computer. Disable Ollama cloud features and select two locally downloaded tags that fit your RAM before running this experiment. Detailed Windows steps are in the README.

Model downloads may be large and need internet. Once installed, inference runs locally if Ollama is using a local model. Check the model licenses.

INTERPRET CAREFULLY

Quality ≠ speed

Exact match reflects this small task only. A lower wall time can reflect warm caches, different model sizes or order, not just quantization.

The app does not measure RAM, accuracy on real users, safety, or production reliability.
